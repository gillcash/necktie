# Necktie evaluation harness

Necktie does not inherit Ponytail performance claims. Any Necktie benchmark must compare the same model, task, evidence, permissions, and environment with and without the relevant Necktie layer.

Measure observable outcomes such as material-error detection, unsupported-claim rate, acceptance-criterion coverage, review convergence, verification success, latency, and token cost. Publish prompts, fixtures, scoring rules, sample sizes, failures, and limitations with every result.

No benchmark result is claimed in this release.
